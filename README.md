# mini-git
PROJECT TITLE- MINI GIT VERSION CONTROL SYSTEM

DESCRIPTION-
Mini Git Version Control System is a mini version built locally to get an insight into how Git works and what are the concepts behind version controlling files. It includes basic functions like creating a repository,tracking of files,staging, committing and viewing history of the project.The project will be implemented using c++ language and the concepts will include Data Structure and Object Oriented programming.

PROBLEM STATEMENT-
Software developers use version control tools like Git every day to save code changes and manage project history,without knowing how it works inside.
